# Shape Multiplication & Division Puzzles · 圖形乘法・除法謎題

An interactive math practice web app for kids, in **English** and **繁體中文**.
給小朋友的互動式數學練習網頁,支援英文與繁體中文。

## How it works · 玩法
- Corners are triangles △, edges are circles ○, the center is a square □.
- **Multiply:** △ × △ = ○ and ○ × ○ = □
- **Divide:** □ ÷ ○ = ○ and ○ ÷ △ = △
- Type numbers into the empty shapes. When every box in a puzzle is filled, the puzzle is checked: wrong answers turn red and bold, right answers turn green.
- 在空白圖形中填入數字。填滿一題後會自動檢查:錯誤的數字顯示紅色粗體,正確顯示綠色。

## Features · 功能
- × Multiply / ÷ Divide switch · 乘法/除法切換
- Choose number of puzzles (2–8), times tables up to 3–9, and difficulty
- Every puzzle has exactly one solution
- Show answers, solved counter, light/dark mode
- Single static file, no build step, no dependencies

## Run · 執行
Open `index.html` in a browser, or publish with **GitHub Pages**
(Settings → Pages → Deploy from branch → `main` / root).
